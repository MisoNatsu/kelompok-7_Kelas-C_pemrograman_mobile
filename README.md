## Projek Akhir: Pustakaku

Aplikasi mobile Flutter untuk mencari, membaca, menyimpan, dan mengulas buku dari Open Library API,
dengan Firebase (Authentication, Cloud Firestore, Cloud Messaging) dan Riverpod. Buku domain publik
bisa dibaca gratis langsung di aplikasi.
